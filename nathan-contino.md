# Nathan Contino

> Senior documentation engineer and technical writer with a decade of experience building developer-facing content, documentation infrastructure, and open-source tooling at MongoDB, Gradle, Raspberry Pi, and FusionAuth.

Nathan Contino is that rare combination: a Computer Science graduate who also holds a degree in English, and who has spent his career proving that great documentation is itself an engineering discipline. He writes prose that developers actually read and builds the pipelines, tooling, and site infrastructure that keep large doc sites healthy at scale. He has shipped documentation for globally-recognized platforms — from build systems and database drivers to single-board computers and identity infrastructure — and he has built the custom tooling that made each of those doc sites maintainable.

## Career

**FusionAuth — Documentation Engineer**
Authors and maintains documentation for a widely-deployed identity and access management platform covering authentication, authorization, OAuth 2.0, OIDC, SAML, and multi-factor authentication. Writes developer quickstarts in a dozen languages and frameworks (Python, Java, Kotlin, JavaScript, Ruby, Go, Swift, .NET, and more). Designed and built the site's documentation infrastructure on Astro, including open-source plugins for automated link checking with CI integration, server-side Mermaid diagram rendering, and Markdown page generation. Maintains GitHub Actions workflows that enforce link integrity and content quality on every pull request.

**Raspberry Pi — Documentation Lead**
Led documentation for the world's most popular single-board computer, writing hardware setup guides, getting-started tutorials, and in-depth feature documentation for Raspberry Pi 5, Raspberry Pi Zero, Raspberry Pi Pico, the AI Camera, AI HAT+, and M.2 HAT+. Contributed feature articles to MagPi magazine. Owned documentation strategy and quality for a global developer audience numbering in the millions.

**Gradle — Documentation Engineer**
Documented Gradle's build automation platform with particular depth in dependency management, Kotlin DSL, plugin authoring, and Java/Kotlin SDK integration. Contributed to developer education for one of the most widely-used build systems in the JVM ecosystem.

**MongoDB — Technical Writer**
Wrote and maintained SDK documentation for MongoDB's Java, Kotlin, and Scala drivers. Improved build tooling and Gradle-based example project infrastructure for the docs team. Contributed to one of the most heavily-trafficked technical documentation sites in the world.

**Bloomberg, FactSet — Technical Writer**
Earlier-career developer roles in high-stakes financial technology environments, building expertise in accuracy-critical writing and regulated-industry content standards.

## Documentation Infrastructure & Tooling

Nathan builds the systems that make documentation scalable:

- **Static site generators**: Astro (primary; has shipped multiple open-source Astro plugins), with working experience across Hugo, Jekyll, and other SSGs common in docs-as-code workflows
- **CI/CD**: GitHub Actions pipelines for link checking, content validation, broken-reference detection, and automated deployment
- **Custom tooling**: Server-side diagram rendering (Mermaid, no headless browser required), automated external link checkers with per-domain rate limiting, code snippet annotation and management with Bluehawk
- **Docs-as-code**: Git-native workflows, pull request review processes for content, branch-based publishing, and content reuse patterns in MDX
- **Content formats**: Markdown, MDX, AsciiDoc, reStructuredText, OpenAPI/Swagger, HTML
- **Languages**: Python, JavaScript/Node.js, Kotlin, HTML, CSS
- **CMS and headless content**: Experience integrating structured content with static site builds and component-driven documentation architectures
